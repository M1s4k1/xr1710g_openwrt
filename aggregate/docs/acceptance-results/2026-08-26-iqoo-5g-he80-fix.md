# 实机测试记录 — iQOO Neo9 5G 兼容性二分定位（issue #21 关闭）

- 日期：2026-08-26（设备本地 CST；UTC 2026-08-26 23:29–23:34）
- 设备：Gemtek XR1710G（`gemtek,xr1710g-ubi`），HTTP U-Boot
- 固件：OpenWrt SNAPSHOT r0-eb7a45b（experimental 档，kernel 6.18.44）
- 客户端：iQOO Neo9（本次 MAC `42:f5:40:1e:e6:e1`，OriginOS 随机 MAC；贴脸信号 -34 dBm）
- 关联 issue：#21（F41/F47）
- 结论：**ch149/HE160（center1 5815，覆盖 5735–5895MHz / UNII-4 前段）被国行 iQOO 在 MAC 层直接拒绝（“拒绝请求”且 AP 侧零 auth/assoc）；改 HE80 后 psk2 与 sae-mixed 均可正常关联。根因是 BSS 频宽/频段，与加密无关。默认 5G 改为 HE80，HE160 转为注释化可选档。**
