## 最优先行动项（跨信息点收敛）

1. **reserved_bmt 66MiB 布局对齐（IP02/IP05/IP06/IP07/IP15 五个 subagent 独立收敛）**：本仓库 `9001/9002` 仍是 2MiB 旧布局，与 master 及上游修复（ee771d3d/72ed389）矛盾，且 `9000` 已声明 compat 2.0 —— 属“声明了修复但补丁没落实”的内部不一致。建议：先实机抓 stock bootlog 核实 XR1710G 的 BMT 池；证实后扩 `reserved_bmt@1be00000 0x04200000` 并同步 `docs/FLASHING.md`。
2. **风扇双控制器去重（IP25 独立发现）**：`files/etc/init.d/fan` 与 9017 内 fancontrol 的 `/etc/init.d/fan` 双入口冲突，属于现存真实缺陷，应合并为单控制器 + 动态探测 + 迟滞/失效兜底。
3. **mt76 0099 tx_failed 与 0103 NPU RX skb->dev（IP25/IP26 交叉验证）**：两个社区真修复，对 c5a3bd91 可干净应用，建议分别入 default 与 experimental。
4. **rdinit 修复（IP17）**：9001 dts chosen bootargs 加 `rdinit=/sbin/init`，消除每次开机假警告，零风险。
5. **sysupgrade compat 一致性（IP15）**：`9000` 的 XR1710G compat 版本先与当前布局对齐（2.0→1.0），待 BMT 布局实证升级后恢复 2.0。
6. **验收方法学补洞（IP20/IP24/IP28）**：ACCEPTANCE 新增 B6 管理面改址回连、C3 外部端点吞吐判据、测试方法学节；并把 OC 报告中的本机 iperf3 数据降级为 CPU 基线。
